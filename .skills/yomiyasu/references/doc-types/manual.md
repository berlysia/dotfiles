# マニュアル（manual）

あわせて読む: domains/tech.md か domains/business.md（中身で選ぶ）
lint で外す規則: excess_list

## 1. 普通な書き方（直さない）

- 番号つきの手順と、1手順1動作。
- 「〜してください」の連続と、注意や警告の欄。
- かぎ括弧の画面の項目名（「保存」ボタン）。
- 読者のために扱う範囲を示す文（「この手順書では、退職の手続きは扱いません」）。AIへの指示の残り（slop-catalog.md 6章）の残す例に当たる。
- 部下・後輩の読み手でも、敬語を下げない（利用者が頼んだときだけ。persona.md 7章）。

## 2. それでも直すもの

- 先に済ませる作業や依頼を括弧に入れた文。括弧から出して、行う順に文で並べる（SKILL.md 2章 Step 2 の5）。手順の数は `ja-fact-preservation` の「消さないこと」に従い、番号は変えない。

## 3. 長さと省略

- 手順の数は `ja-fact-preservation` の「消さないこと」に従う。順を変えない。文を分けても手順は分けない。

## 4. 例（合成）

| 元 | 扱い |
|---|---|
| 3. 「保存」を押してください。 | 残す（1手順1動作。画面の項目名） |
| 4. 設定を確認し、問題がなければ再起動してください。 | 残す（条件が再起動だけに掛かる。手順を2つに分けない） |

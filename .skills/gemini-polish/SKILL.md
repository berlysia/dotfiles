# gemini-polish

Google Antigravity CLI（`agy`）経由で Gemini モデルを呼び出し、テキストの校正・推敲を行うスキルです。
CLI コマンド `gemini-polish`（別名: `agy-polish`）または `agy -p` を使用して、指示・トーンに沿った推敲結果を取得します。

---

## 1. 推敲の基本原則

- **事実・意味の保持**: 原文の意図、条件、数値、固有名詞・識別子を勝手に改変・捏造しない。
- **読みやすさの向上**: 誤字脱字、主述のねじれ、不自然な助詞や接続、二重否定、過度な受動態を整える。
- **トーンと場面の適合**: 利用者の要求や文脈（ビジネス、技術文書、カジュアル、簡潔重視など）に最適な表現を選ぶ。

---

## 2. CLI の利用方法

本環境には `~/.local/bin/gemini-polish`（および `agy-polish`）が配備されています。

### 基本構文

```bash
gemini-polish [options] [file]
gemini-polish [options] --text "推敲したいテキスト"
echo "テキスト" | gemini-polish [options]
```

### 主なオプション

| オプション          | 引数     | 説明                                                                                             |
| :------------------ | :------- | :----------------------------------------------------------------------------------------------- |
| `-t, --tone`        | `<tone>` | トーン・スタイル指定（`standard`, `business`, `casual`, `concise`, `technical`、または自由記述） |
| `-i, --instruction` | `<text>` | 推敲にあたっての追加の個別指示（例:「箇条書きでまとめる」「敬体ではなく常体で」）                |
| `-r, --raw`         | なし     | 解説や選択肢を省き、推敲後の本文テキストのみを出力する                                           |
| `-m, --model`       | `<name>` | 使用するGeminiモデル（デフォルト: `gemini-3.8-flash-medium`）                                    |
| `--text`            | `<text>` | 引数から直接テキストを渡す                                                                       |

### トーン指定の一覧

- **`standard`**（デフォルト）: バランスの取れた、自然で読みやすい標準的な日本語。
- **`business`**: ビジネスメール、社外向け文書、改まった報告書に適した丁寧な敬語表現。
- **`concise`**: 冗長な前置きや重複表現を削ぎ落とし、要点を明確に引き締めた文章。
- **`technical`**: 主述関係を明確にし、論理的・客観的・正確に記述した技術ドキュメント向け文章。
- **`casual`**: ブログ、SNS、気軽な社内チャット向けのフランクで親しみやすい表現。

## 3. 利用例

### 1) ビジネスメール・連絡文の推敲

```bash
echo "明日休む連絡です。風邪引いたのでよろしく。" | gemini-polish -t business
```

### 2) 簡潔化して推敲後本文のみを取得する（`--raw`）

スクリプトやパイプ処理、ファイル上書きなどで解説文が不要な場合は `-r`（または `--raw`）を指定します。

```bash
gemini-polish -t concise -r draft.txt > polished.txt
```

### 3) ファイルの推敲と個別指示の追加

```bash
gemini-polish -t technical -i "用語の定義を明確にし、能動態を中心に記述してください" docs/architecture.md
```

### 4) 高性能モデル（`gemini-3.8-flash-high`）での実行

```bash
gemini-polish -m gemini-3.8-flash-high --text "この機能は問題が発生する可能性が存在しています。"
```

---

## 4. 直接 `agy -p` を実行する場合の手順

CLI ラッパーを通さず、エージェントが柔軟にプロンプトを構築して推敲を依頼する場合は、以下の形式で `agy` を直接呼び出します。

```bash
agy -p "$(cat <<'EOF'
あなたは文章の校正・推敲を行うプロフェッショナルです。
以下のテキストを自然で読みやすい日本語に推敲してください。
事実や条件は変えず、主述のねじれや冗長な表現を正してください。

【対象テキスト】
<推敲対象のテキスト>
EOF
)" --model gemini-3.8-flash-medium
```

---

## 5. エージェントの対応フロー

エージェントが利用者から推敲・校正を依頼された場合は、以下の流れで対応します:

1. **推敲対象と文脈の確認**: 対象テキスト、想定する読み手・場面（ビジネス、技術解説、チャット等）を確認する。
2. **ツールの実行**: `gemini-polish` CLI または `agy -p` を呼び出して推敲案を取得する。
3. **結果の提示**:
   - 推敲後の文章を明示する。
   - 変更した主なポイント（ねじれの解消、トーンの統一、冗長性の削減など）を簡潔に添える。
   - 必要に応じて、文体やニュアンスが異なる別案（丁寧度合いの違いなど）を提示する。

## 起きたこと

- delegation の route の出力と ADR-0057 で、週枠のペースを「線」と呼んでいた。
  表示の例は「線まで 2.1h」「線に届かない」で、model-offloading の rule には「ペースの線」とある。
- 「線」の中身は、その時点までに使ってよい週枠の割合である（ADR-0055 K5）。
  使用率のグラフ上の直線を思い浮かべて付けた名前で、図を見ていない読者には何の線か分からない。
- 利用者の指摘（提案を出したセッションでの発言の引用）:「『線』ってなに、言葉遣いが美しくない」
- 表示とテストと ADR の言い換え（案は「目安」）は、別の作業として利用者に渡してある。
  このファイルでは扱わない。

## やること

- `.skills/ja-notation/SKILL.md` に、筆者が思い描いた図から取った呼び名を拾う項目を足す。
  - 例: 週の使用率を「線まで 2.1h」と書いたときの「線」。
  - 既定の直し方: その値が何を表すかで呼ぶ。
    何を表すかが原文と前後から決まらなければ、語を残して筆者に確かめる。
- 新しい項目にするか、既存の項目を広げるかを決める。
  近い既存の規則は次の 3 つで、どれも図のたとえとは少しずれる。
  - japanese-tech-writing の「役割や位置を場所や物にたとえる語」
  - japanese-tech-writing の「術語の響きを持つ語を、術語でない場面に流用しない」
  - ja-notation の「仕組みを場所にたとえて指した名詞」

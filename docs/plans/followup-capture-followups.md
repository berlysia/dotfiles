# 残件の入口の作業から持ち越した課題

ADR-0030 の作業が、範囲の外に回した課題である。
決定は `docs/decisions/0030-followups-written-when-raised.md` にある。

## 「記録を移す」手順の見直し

- **内容**: 計画の最後のタスクが記録を移す手順を、表の行ごとの行き先の記入から、原本の見出しごとの照合へ見直す。
- **分かっていること**:
  - 表の行ごとに行き先を書く手順では、行に該当する内容を狭く読むと漏れる。research の「未確認」の節と、「移さない」行の中にあった検証のコマンドが、1 回目の移し替えで落ちた。
  - 漏れに気づけたのは、原本の見出しの一覧を、1 つずつ「どこへ行ったか」と突き合わせたときである。
  - 事例はこの 1 件だけである。手順を足すと、今後のすべての作業の終わりに費用が掛かる。
- **未決**: 見出しごとの照合を、毎回の作業に足すかどうか。

# 英語と一語ずつ対応する直訳を機械で見つける

## 困っていること

直訳語の一覧は、名指しされた語を正規表現で探す。語の組み合わせで直訳調になる文（「最も手軽な偽りの手口は … なので閉じない」）は、どの語も単独では普通の日本語なので、一覧では見つけられない。

ja-notation の「英語を一語ずつ直訳した表現」の節は、こうした文をモデルが読んで見つけるための目印である。ただ、モデルはどの日本語も英訳できるので、「英語に戻せる」だけでは判定にならない。

## 考えている方法

利用者の見立てでは、形態素解析で文を分け、英訳の語と前後を対応付ける処理になる。

- 日本語の文を Sudachi で語に分ける（japanese-check がすでに使っている）。
- 英訳を作り、日本語の語と英語の語を対応付ける。
- 語の順まで英語と一対一に対応し、しかも日本語の語を文字どおりに読むと意味がずれる箇所を候補にする。

## 決めていないこと

- 英訳と意味のずれの判定を、何で行うか。LLM を呼ぶなら、hook の時間の上限（5 秒）の中では動かせない。
- 候補を警告として出すか、推敲のスキルの中で確かめる材料にとどめるか。

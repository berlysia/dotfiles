# plan 層の重さの見直し（未着手）

Document Workflow の plan は、実装とほぼ同じ水準まで書かれている。
そこまで書くなら、plan を書かずに実装した方がよいのではないか。
2026-10-07 の作業（ADR-0029、PR #275）の終わりに、利用者が挙げた論点である。

## 発端

`docs/plans/` の掃除で、嵩の 75% が plan だと分かった。
ADR-0029 で plan を commit しなくなったので、plan はもうリポジトリを膨らませない。
残る費用は、plan を書く時間、レビューが読む量、承認する人が読む量である。

## 確定した事実

- 2026-10-07 の計測で、`docs/plans/` の plan は 52 本・43,486 行だった。1 本あたり平均 836 行、最大 2,266 行である。
- plan のテンプレートは、タスクごとに失敗するテスト、最小実装、実行するコマンドと期待を書くことを求める。`rules/workflow.md` の No Placeholders 禁則は、「後で実装」「上記と同様」などを禁じる。
- ADR-0029 の plan-1 は約 600 行だった。内訳は、Files の列挙が約 110 行、36 行の書き換えの表が約 100 行、新しいファイルと挿入する段落の全文が約 90 行である。
- その plan の T2〜T6 を、下位モデルの subagent が 155 秒・逸脱 0 件で実行した。
- 同じ作業で、spec は 4 ラウンド、plan は 2 ラウンドのレビューを通した。
- ADR-0015 は、計画フェーズが総ターンの 70〜98% を占めるという観測から始まっている。
- ADR-0028 の委任は、spec の承認時に plan-N の承認を省けるようにした。plan を書くことと、plan のレビューは残している。

## plan が担っている役目

plan をやめる、または軽くする場合、次の役目の置き場を決める必要がある。

| 役目                                 | 根拠                                                                          |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| 人間が書き込みの前に承認する単位     | gate は、承認済みの plan の Files に載ったパスへの書き込みを通す              |
| 保護対象への書き込みを人間が見る機会 | ADR、規則、skill への書き込みは委任できず、plan の承認が要る                  |
| 下位モデルへ渡せる粒度の指示         | `rules/model-offloading.md` は、plan が確定していることを委譲の条件にしている |
| 実装の前に誤りを見つける場           | ADR-0029 の plan のレビューは、設計が見落とした 3 行の参照を見つけた          |
| 計画から外れた点の基準               | 「記録を移す」タスクは、plan と実際の差を ADR に書く                          |

## 未解決の設計判断

- plan のどの部分が、実装の前に要るのか。Files（承認の単位）と判定基準は要りそうだが、テストと実装のコードの全文が要るかは決まっていない。
- 承認の単位を何にするか。候補は、今のまま plan、spec だけ（差分は PR で見る）、Files と判定基準だけの短い plan、の 3 つ。
- レビューをいつ行うか。plan に対して行うのか、実装した差分に対して行うのか。
- 下位モデルへの委譲をどう保つか。plan が薄くなると、委譲する指示の粒度を別に確保する必要がある。
- どの種類の作業に当てるか。ADR-0029 の plan-1 は文書の書き換えで、コードの変更はコメント 2 行だった。コードを書く作業でも同じことが言えるかは、確かめていない。

## 確かめていないこと

- plan を書く時間と、実装の時間の比。上の「155 秒」は実装の側だけの数字で、plan を書いてレビューを通すのに掛かった時間は測っていない。
- plan のレビューが見つけた誤りのうち、実装した差分のレビューでも見つかったはずのものの割合。

# 英語を一語ずつ写した表現の残件

`.skills/ja-notation/SKILL.md` の「英語の言い方を一語ずつ写した表現」の節は、3 つの型の目印として入れた。下の節がすべて片付いたら、このファイルを消す。

## 辞書の訳語で置いた名詞を拾う

承認（authorize）、要求（request）、事実（facts）、影響（impact）のように、英語の用語を辞書の訳語で置いた名詞は、今の節では目に留まらない。型として足す案は評価で効果が出ず見送った（経緯は節を足した commit の本文）。モデルはこれらを定着した言い方として扱う。

着手の条件: 上流 yomiyasu（nanaism/yomiyasu）が、同じ点検を次のマイナーで足すと予告している。取り込んだとき、上流の点検がこの層を拾うかを見る。拾わなければ、型の説明ではなく語を名指しする方式（slop-catalog の章と同じ形）を ja-notation の「追加の項目」に置くかを決める。名指しする語の選び方を含むので、着手するときは Document Workflow（plan.md）を通す。

## 場所の名詞に推測で名前を付ける

「トークンを出す口」を、評価文に無い「エンドポイント」に直す動きが、節の有無にかかわらず出た。節は名前が書かれているときだけ置き換えると決めたが、出どころは yomiyasu の SKILL.md の「専門用語と名称の扱い」で、上流の規則は変えていない。上流を取り込むときに、この規則が推測を止める書き方になったかを見る。

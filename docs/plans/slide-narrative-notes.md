# 短い発表の組み立てを練り直す

今後の検討の方向として、利用者の言葉をそのまま残す。

「これはもうちょい練りが必要。発表の短さではなく文脈に依存する。聞き手の状態をどう想定して、どう動かしていくか、何を相手の頭のスタックに積んでいくか、積みすぎないようにコントロールするかから考える」

以下は、上の方向に照らして再検討する材料である。発表一般の規則としては、まだ使えない。

- 10 分の発表について、柱の数よりも一つの話をどこまで具体的に示すかが記憶に残る量を左右する、という観察があった。網羅を優先した資料で薄くなっていた実物の画面や失敗談を、どこに加えるかを見直す。
- 冒頭の結論を反復する案は、その結論に納得できる材料を先に示せているかと合わせて見直す。失敗談は、その材料の候補だった。
- 軽い設定から重い設定へ進む構成では、重い設定をお手本として示さず、その先の実例として見せる配分を試した。聞く人の多くが初期の段階にいるという当時の想定が妥当かも確かめる。
- 出来合いのスキルで文章によって頼む方法と、自前の hook で機械的に制限する方法の比較を、設定の段階を示す図の中に位置づけた。この位置づけが理解を助けるかを再検討する。
- 生成した見出しでは、読点で二拍に分ける形と対句の対称性が本人らしさを損ねた、という観察があった。一拍で言い切る形や問いで切る形を、内容と合わせて見直す。
- スライドでは記号で並列や順序を示す案を試し、声に出すノートでは息継ぎと係り方のために読点を残した。画面と発話で必要な表現の違いを再検討する。

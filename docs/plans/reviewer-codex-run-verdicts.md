## 再開するときの手順

1. 判定の行がすべて同じ値なら、その値を採って成功にする。値が食い違うときだけ失敗にする。
2. 失敗のときも、本文の末尾を決まった区切りで出力に含める。今は中継が本文を返すかどうかで、結果が残るかが決まる。
3. brief が判定の書式を指定していたら起動前に警告するかは、1 の後で要否を決める。

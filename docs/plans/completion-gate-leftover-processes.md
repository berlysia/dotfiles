# completion gate が止めない子プロセス

## 今の形（2026-10-21 に観察）

- completion gate は check をプロセスグループで走らせる。時間切れか出力上限で打ち切ったときは、グループに SIGTERM を送り、猶予の後に SIGKILL を送る。gate 自身が SIGTERM / SIGINT で止められたときも、グループに SIGKILL を送る
- 打ち切らずに終わった実行（成功・失敗）の後は、グループに残ったプロセスを止めない。テストが起動して終了を待たずに残したプロセスは、そのまま動き続ける
- check のコマンドが起動できなかったとき（`spawn` の `error`、pid が無い）の分岐は、テストが無い。`shell: true` で起動しているので、テストから起動の失敗を作れなかった

## やりたいこと

打ち切らずに終わった実行の後に、グループに残ったプロセスも止める。

## 決めること

- 止めてよい時点: 直接の子が終わった後、グループが空になると、その番号は別のプロセスの pid として再利用されうる。`kill(-pid)` を送る前に、そのグループが今回の実行のものだと確かめる方法が要る
- 止めてよい相手: テストが意図して残すプロセス（常駐させる daemon など）があるか

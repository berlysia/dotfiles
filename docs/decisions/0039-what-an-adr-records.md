# ADR-0039: ADR は決定と、再検討に要る事柄だけを書く

## Status

accepted (2026-10-21)

## Context

ADR は 40 本、588KB に膨らんでいた。決定を読むのに要らない節が、決定の文を埋もれさせていた。検証の記録、計測の内訳、関数名や行番号の写し、作業の経過（計画や spec からの差、レビューの周回）、未対応の課題、操作の手順などである。

膨らんだ力学は、作業の終わりに成果物を恒久の文書へ移す規則（ADR-0029 K1）にあった。研究の計測と、計画から外れた点を、節ごと ADR へ送る行があった。どの行にも当たらない内容を ADR の Context へ送る受け皿の行もあり、量の上限が無かった。記録を移さないと戻らないという前提（ADR-0029 R1）も、書き過ぎる向きに働いた。

## Decision

- **K1: ADR の `##` 見出しは 7 つに限る。** Status、Context、Decision、却下した代替案、Consequences、Amendments、References である。Status、Context、Decision は必ず書く。決定の ID は Decision に、リスクの ID は Consequences に置き、どちらも振り直さない。
- **K2: ADR に書かないものを決める。** 検証の手順と出力、試しの記録、計測の内訳、関数名・定数・行番号・テスト名の写し、作業の経過、未対応の課題、操作の手順、作業用ディレクトリのパス、既定のブランチから辿れない commit、PR の番号である。ここでいう作業の経過には、計画や spec からの差の経過を含む。決定の帰結として残る制約は、経過ではないので Consequences に書く。
- **K3: 計画から外れた点は、中身で行き先を振り分ける。** 決定そのものが変わったら Amendments に書き、変えた後の決定を Decision に反映する。決定の帰結として残る制約や限界は、Consequences に 1〜3 行で書く。plan に無かった小さな判断は commit の本文に、なぜこうしないかはコードのコメントに、終わらなかったことは持ち越しの課題の一覧に書く。作業の経過は残さない。研究から ADR へ送るのは、決定を支える数値と事実だけにする。数値には測った条件を添える。
- **K4: 運用中に照合する基準の本文は、document-workflow-reference skill の記録の移し方の文書に置く。** 配られる文書は、このリポジトリにしかない ADR を名指しできない（ADR-0025）。この ADR は決定と理由を持ち、基準の本文は持たない。
- **K5: この基準を ADR-0001〜0038 に一度だけ当てる。** 書き換えない記録として扱ってきた ADR も対象にする。ADR-0017 R4 の「当時の記録なので書き換えない」は、この決定が上書きする。以後の ADR は、書くときからこの基準に従う。
- **K6: 機械で判定できる部分をテストで検査する。** 見出しの集合、作業用ディレクトリのパス、ADR への行番号の参照、ソースへの行番号の参照、文書に書かれたパスの実在である。既存の ADR の違反は例外の一覧に載せて通し、直したら一覧から外す。一覧に載っているのに違反していない ADR があれば、テストが落ちる。

## 却下した代替案

- **ADR を白紙から書き直す。** 決定とリスクの ID を、コードのコメント、テスト、他の ADR が参照している。書き直すと ID の対応を全件取り直すことになる。
- **基準の本文をこの ADR に置き、規則から参照する。** 配られる文書は ADR を名指しできない。
- **計画から外れた点を ADR に一切書かない。** 決定を再検討するときに、実装で分かった制約を知らないと判断を誤る。帰結として残る制約だけを、行数を限って書く。
- **禁止語を機械で検査する。** 検証の記録や作業の経過は、書き方が多様で誤検出が多い。

## Consequences

- 7 つの見出しに収まった後の、節の中身の膨らみはテストで止めない。止めるのは基準と、記録を移すタスクのレビューである。振り分けの当て方、特に Consequences に送る 1〜3 行は、書き手の判断に依る。
- 再検討の条件: ADR-0001〜0038 を直した後に書かれた ADR に、計測の内訳や関数名の写しが戻ったら、その形を機械の検査に足す。
- 文書に書かれたパスの実在を検査するので、消したファイルを文書に書いたままにはできない。消したファイルは、移した先を書くか、既定のブランチから辿れる commit で指す。
